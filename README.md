# Rustlings

## Structure

```
exercises/   # exercise files to edit (each has a TODO marker)
solutions/   # reference solutions
```

## Usage

```bash
cargo install rustlings
rustlings
```

Jump to a specific exercise:

```bash
rustlings run variables1
rustlings hint variables1
```
